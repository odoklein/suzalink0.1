# Suzalink logo

Approved route: « le fil », one line folded into an S, ending in two dots, with
the "suzalink" wordmark. Redrawn as vectors from the generated concept
(2026-09-30): the symbol is built from exact arcs (180° symmetric), the
wordmark is Satoshi Bold outlines with a round blue dot on the i, so no font
is needed to display it.

| File | Use |
| --- | --- |
| suzalink-logo.svg | Default: blue symbol and i-dot, ink wordmark, on white or light backgrounds |
| suzalink-logo-white.svg | All white, on the brand blue, on photos or on dark backgrounds |
| suzalink-logo-ink.svg | One colour (ink), for print or engraving |
| suzalink-symbol.svg | Symbol alone, blue |
| suzalink-app-icon.svg | White symbol on a blue rounded square: app icon, social avatar. Also `src/app/icon.svg` (favicon) |

Colours: blue `#3355FF`, ink `#0B1220`. The site draws the logo from
`src/components/layout/logoPaths.ts`, generated from the same geometry.

Rules: keep clear space around the logo equal to the height of the symbol's
end dot; don't stretch, recolour outside the two brand colours, outline, or add
shadows; below 24 px tall, use the symbol alone.
